# TabFlow — Chrome 浏览历史管理扩展 设计文档

## 概述

TabFlow 是一款 Chrome 浏览器扩展，用于高效管理和检索浏览历史。支持关键词搜索标题和 URL 参数，提供快速查找、分组浏览和批量管理功能。

## 技术栈

| 层 | 技术 |
|---|---|
| UI 框架 | React 18 |
| 样式 | 纯 CSS（无第三方 UI 库） |
| 存储 | chrome.storage.local（缓存搜索建议和用户设置） |
| 图标 | SVG 图标 |
| 构建 | Webpack 或 Vite（打包 React） |
| 后台 | Service Worker (Manifest V3) |

## 数据来源

使用 Chrome 原生 `chrome.history` API 读取浏览历史，所有搜索和管理操作直接查询浏览器历史引擎。扩展不自行建立历史数据库，不存储用户浏览记录。

所需权限：`history`

## 架构

```
Chrome Extension (Manifest V3)
├── Popup (popup.html)
│   └── React App — 快速搜索入口
├── Management Page (history.html)
│   └── React App — 完整历史管理中心
└── Service Worker (background.js)
    └── chrome.history API 查询 + chrome.storage 管理
```

**数据流**：Popup/管理页 → chrome.runtime.sendMessage → Service Worker → chrome.history API → 返回结果

## 功能规格

### 1. Popup 快速搜索

#### 界面状态

**初始状态**：
- 搜索框（placeholder: "搜索标题或 URL..."）
- 历史搜索建议列表（从 chrome.storage.local 读取，最多 5 条）

**输入状态**：
- 用户输入实时匹配建议下拉
- 建议来源：过去搜索记录 + 当前输入前缀匹配的访问频率最高的标题
- 关键词高亮显示

**搜索结果状态**：
- 每条结果展示：
  - 页面标题（匹配关键词高亮）
  - URL（匹配参数高亮）
  - 访问次数 · 相对时间（如"10 分钟前"）
- 点击跳转到对应 URL
- 底部"查看全部 N 条结果 →"按钮，点击打开管理页面（history.html）并携带搜索参数

#### 边界状态

- **无结果**：显示"未找到匹配记录"，建议调整关键词
- **加载中**：显示轻量加载指示
- **Chrome API 繁忙**：超时提示重试

### 2. 管理页面 (history.html)

#### 布局

```
┌──────────────────────────────────────────────────────────┐
│  [Logo]  TabFlow    [🔍 搜索框]                           │
├──────────┬───────────────────────────────────────────────┤
│ 📋 全部  │  搜索结果列表                                  │
│ 📁 域名  │  每项: ☐ 标题 / URL / 时间·次数 / ⋯          │
│ 📅 时间  │                                               │
│          │  [按访问时间] [按访问次数]  [共 N 条结果]      │
│ ───────  │───────────────────────────────────────────────│
│ 🗑️ 管理  │  批量操作栏 (勾选后显示)                      │
└──────────┴───────────────────────────────────────────────┘
```

#### 三种视图

1. **全部历史**：搜索后的完整结果列表，支持按访问时间/次数排序
2. **按域名分组**：域名 → 折叠展开该域名下的页面列表
3. **按时间分组**：今天 / 昨天 / 本周 / 更早，每段显示条数

#### 操作功能

**批量操作**（勾选后显示操作栏）：
- 批量删除选中记录
- 按域名一键清理（删除该域名所有记录）
- 按时间段清理
- 导出为 CSV / JSON

**单条操作**（点击 ⋯ 菜单）：
- 在新标签页打开
- 复制 URL
- 删除该条记录

#### 搜索

- 全局搜索框，输入关键词实时过滤
- 从 Popup 跳转时自动携带搜索词
- 支持搜索标题关键词和 URL 参数片段

### 3. Chrome 权限

```json
{
  "permissions": ["history", "storage", "tabs"],
  "host_permissions": ["<all_urls>"]
}
```

### 4. Storage 结构

```typescript
interface StorageSchema {
  recentSearches: string[];         // 最近搜索记录，最多 20 条
  settings: {
    maxResults: number;             // 每页显示条数，默认 50
    defaultView: 'list' | 'domain' | 'time';  // 默认视图
  };
}
```

## 错误 & 边界状态

| 场景 | 处理方式 |
|---|---|
| 首次安装无权限 | 弹出引导提示，引导用户到扩展管理页授权 |
| 搜索无结果 | 显示"未找到匹配记录"，建议更换关键词 |
| Chrome API 超时 | 显示加载状态，超时后提示重试（重试按钮） |
| 管理页无数据 | 空状态提示"开始浏览网页吧" |
| 大量历史查询 | Service Worker 分页查询，UI 显示加载更多 |
| Popup 弹出延迟 | 显示骨架屏或简短加载文本 |

## 非功能性需求

- 搜索响应时间 < 500ms（基于 chrome.history API 性能）
- Popup 首次加载 < 1s
- 管理页面按需加载，不预加载数据
- 所有操作有即时反馈（加载态 / 成功 / 失败提示）
- 支持 Chrome 最新稳定版
